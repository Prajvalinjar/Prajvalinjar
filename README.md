### 🔄 RecoverFlow — Payment Recovery Operations Platform

RecoverFlow is a payment recovery operations platform designed to help engineering, operations, and finance teams understand failed payments, monitor recovery workflows, and make safer recovery decisions.

The platform provides a unified operational view of payment recovery, failed transactions, recovery cases, analytics, and execution safeguards.

#### Key Features

- Payment recovery command center
- Failed transaction and recovery case visibility
- Recovery workflow monitoring
- Revenue-at-risk and revenue-recovered analytics
- Recovery rate and attempt tracking
- Recovery health and lifecycle distribution
- Jobs and queue monitoring
- Reconciliation and operational insights
- Deterministic recovery policy engine
- AI-assisted recommendations
- Execution safeguards and audit visibility
- Clearly labelled sandbox and production data modes
- Backend health monitoring
- Production-style deployment architecture
- API health monitoring through UptimeRobot

### 🏪 StoreRate — Store Discovery and Reputation Platform

StoreRate is a full-stack store discovery and business reputation platform that connects consumers with local businesses through ratings, reviews, business analytics, and role-based administration.

#### User Roles

- **User** — Discover stores, search businesses, submit ratings, and manage profile
- **Store Owner** — Monitor ratings, reputation, trends, and store performance
- **Admin** — Manage users, stores, ratings, and platform-level operations

#### Key Features

- User registration and login
- JWT-based authentication
- Role-based access control
- Store discovery and search
- Category and rating filters
- Customer ratings and reviews
- Store-owner reputation dashboard
- Admin management console
- Rating analytics
- PostgreSQL database integration
- Input validation
- Secure password handling
- Production deployment
